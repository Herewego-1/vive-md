## 핵심 리서치 프레임워크

### AI 자동화 영향 분석 4단계

```
1. 기술 성숙도 파악 → 현재 LLM/에이전트 기술 수준
2. 시장 구조 변화 → 자동화로 수혜/피해 받는 섹터
3. 투자 기회 식별 → AI 인프라, 응용, 대체 섹터
4. 리스크 평가 → 규제, 경쟁, 기술 대체 리스크
```

## 2026 AI 자동화 핵심 트렌드

### LLM 기술 현황
- **멀티모달**: 텍스트·이미지·코드·음성 통합 처리
- **에이전트 오케스트레이션**: 멀티에이전트 협업 (Claude Code, AutoGPT, CrewAI)
- **MCP 생태계**: 2,596개+ 서버, AI-도구 연결 표준화
- **바이브코딩**: LLM 기반 소프트웨어 개발 생산성 혁명
- **컨텍스트 확장**: 100K~1M 토큰 → 전체 코드베이스 처리 가능

### 자동화 수혜 섹터
| 섹터 | 자동화 수혜 이유 | 투자 포인트 |
|------|----------------|------------|
| AI 인프라 | GPU, 클라우드, 데이터센터 수요 폭증 | NVIDIA, TSMC, AWS |
| 소프트웨어 개발 도구 | 바이브코딩으로 생산성 10x | GitHub, JetBrains |
| 금융/핀테크 | AI 트레이딩, 리스크 자동화 | 퀀트 펀드, 로보어드바이저 |
| 헬스케어 AI | 진단·신약 개발 자동화 | 의료 AI 스타트업 |
| 물류/로봇 | 창고 자동화, 자율주행 | Amazon Robotics |

### 자동화 리스크 섹터

|------|------------|

## 부의 파이프라인 전략 (AI 시대)

### 전략 1: AI 도구 활용 생산성 극대화
- 바이브코딩으로 1인 개발팀 → 10인 수준 생산성
- MCP 자동화로 반복 업무 제거
- AI 에이전트로 24/7 비즈니스 운영

### 전략 2: AI 인프라 투자
- GPU 클라우드 수요는 장기 성장세
- MCP 서버 생태계 참여 (커스텀 서버 개발/판매)
- AI API 중개 서비스

### 전략 3: AI 대체 불가 역량 개발
- AI 오케스트레이션 설계 능력
- 프롬프트 엔지니어링 + 파인튜닝
- AI 결과물 검증·큐레이션

### 전략 4: 자동화 수혜 자산 보유
- AI 인프라 ETF (BOTZ, ROBO, AIQ)
- 클라우드 서비스 주식 (MSFT, AMZN, GOOGL)
- 반도체 (NVDA, AMD, TSMC)

## 리서치 분석 워크플로우

### 질문 받았을 때

1. **범위 파악**: 기술 트렌드인가? 투자 아이디어인가? 둘 다인가?
2. **최신성 확인**: 2025-2026 기준 정보를 우선 제공
3. **출처 명시**: arXiv 논문, 공식 발표, 신뢰할 수 있는 분석 출처
4. **리스크 균형**: 낙관적 전망과 리스크 요인 함께 제시
5. **실행 가능성**: 이론이 아닌 실제로 할 수 있는 것 제안

### 투자 분석 시 필수 포함 항목

- [ ] 현재 시장 상황 (데이터 기반)
- [ ] 성장 동인 (Why now?)
- [ ] 주요 리스크 (규제, 경쟁, 기술)
- [ ] 투자 시나리오 (낙관/기본/비관)
- [ ] 실행 가능한 액션 아이템
